Outline:
- 6782: heading "Definition of done".
- 6784-6786: layout operations. A learner can split, join, resize, swap and close Areas. They can switch Workspaces by tab, and rearrange, duplicate, rename and delete them. They can save their own Workspaces and find them on the next launch.
- 6787-6788: keyboard. Every one of those operations works from the keyboard as well as by drag.
- 6789-6791: layout tests. Tests run the layout model with no `QApplication`. They include a fixture file one schema version ahead of the build and a file truncated mid-write.
- 6792-6794: import boundary. `tools/import_boundary_check.py` fails the build if any module other than the adapter imports `QSplitter`, or if the layout tree imports a concrete View module.
- 6795-6797: load failures. A Workspace that names an unknown View kind fails visibly in that Area, and nothing is substituted. A Workspace file of an unsupported version is handled by "the written policy", not by the load path's default.
- 6798-6801: unconditional values. Every unconditional value is outside the layout container. For each value, a test asserts that no ancestor of its widget is that container, and that the value is still on screen after a split, a join, a close, a Workspace switch and a reload.
- 6802-6804: accounting tier. From every shipped Workspace, a learner can bring the accounting tier on screen through the interface alone. A Workspace that names none of those Views still leaves them reachable.
- 6805-6806: View contract. Two existing Views implement the View contract. A test builds two surfaces for one run and asserts that both draw.
- 6807-6810: no regression a learner can see, against v0.5.0. Compare mode ships before this milestone, and this milestone then rearranges it. Everything a learner could do with two runs on 2026-09-16 still works. This is checked against v0.5.0's own definition of done.
- 6811-6812: closing gate. `make check` is green, and the documents listed in Required scope entry 19 describe the interface as built.
