Outline:
- 828: heading "Spend the monthly API credit on delegable items".
- 830–849 (one paragraph, three points):
  - (830–834) What the credit pays for. Max 20x includes $200 a month of Claude Platform API credit. It pays for `claude -p` only with an API key from the Console organization linked to the credit, and never for a cloud session. Unused credit expires at the end of each billing cycle (https://support.claude.com/en/articles/17154008, read 2026-10-19).
  - (835–845) What the runner does. `tools/headless_worker.py` spends the credit on the items that `bin/docket delegable` lists (`PL-80R5`). Each run clones the repository, works one item on Opus 5.5 following `docs/worker.md`, and pushes `claude/<id>-worker`. It subtracts the reported cost from the credit-left figure given at launch. The runner stops before a run the credit left cannot cover. It stops after any failed run, because an empty credit, a lost connection or a sleeping Mac makes every later run fail (`PL-44SP`). Every run uses the effort level in `.claude/settings.json`, `high`, the level that § "Match effort to the standard the work is held to" sets for sessions (`PL-4N0K`).
  - (845–849) How to start it. Run it on your Mac, from a checkout of `main`, with `claude` and `uv` installed. Start it through `uv run python`, never a bare `python3`, because macOS's `python3` is Xcode's Python 3.9 and the tools need 3.11. `uv run` also puts the project's Python first on `PATH` for the workers (`PL-W38C`).
- 851–862: Mac tool versions.
  - A worker runs `make check` before it commits, so the Mac needs bash 5.2 or newer and GNU Make 4 or newer.
  - macOS ships bash 3.2 and GNU Make 3.81. With them, 89 tests fail whatever the change, so a worker cannot see its own failures (`PL-TSH9`).
  - `brew install bash make` installs both. Homebrew installs make as `gmake`. Adding `export PATH="$(brew --prefix)/opt/make/libexec/gnubin:$PATH"` to the end of `~/.zshrc` makes it `make` in a new Terminal window (the formula's caveat, `Formula/m/make.rb` in Homebrew/homebrew-core, read 2026-10-19).
  - `bash --version` and `make --version` then print 5.3 and 4.4.1 or newer.
  - The runner refuses to start, before it spends any credit, while bash or make on `PATH` is older than bash 5.2 or GNU Make 4 (`PL-44R1`).
- 864–866, step 1: claim the credit on claude.ai under Settings, Billing, API credits, Link organization. This links one Console organization, and changing it later needs a request to support.
- 867–868, step 2: create a key in that organization on platform.claude.com under API keys, Create key.
- 869, step 3: run `export ANTHROPIC_API_KEY=<the key>` in the shell you run from.
- 870–874, step 4: read the credit left at platform.claude.com/settings/billing, under **Promotional credits**. The runner takes it as `--credit-left` for two reasons: the account cannot read the Console's Cost API, and a figure kept on the Mac would miss spending made elsewhere (`PL-NQ0M`).
- 875–878, step 5: dry run with `uv run python tools/headless_worker.py --credit-left 197.72 --dry-run --runs 3`, using the figure from step 4. It prints the items it would run and the credit left, and starts nothing.
- 879–890, step 6: real run.
  - `uv run python tools/headless_worker.py --credit-left 197.72 --runs 3` runs the items one after another.
  - On macOS, the runner keeps the Mac awake with `caffeinate -i` until the batch ends, so you no longer need to start it under `caffeinate` yourself. Keep the lid open, because caffeinate's manual does not say it keeps the Mac awake with the lid closed (`PL-BT70`).
  - Each run prints one line: the item, its effort, the cost and the branch it pushed. A run that pushed adds a second line that names its record.
  - A run that pushed everything removes its clone and keeps its log in `~/.local/state/open-anesthesia-sim/workers/`. A failed run, or a `--no-push` run, keeps both the clone and the log, and its line names the clone (`PL-TX7K`).
- 892–910 (one paragraph, four points):
  - (892–902) Reviewing a worker's branch. Review each branch as delegated work: run `bin/docket verify <id>`, then open the pull request. A pushed run commits its record to the branch as `docs/worker-runs/<branch>-<started>.json`, and the run's line names that file. Before opening the pull request, the reviewing session runs `python3 tools/worker_runs.py review <file> --outcome accepted|fixed|sent-back --note "<one line>"`, and `make check` fails until it does (`PL-87BR`). The records are how headless work is compared with chat-session work, so a sent-back branch's record still belongs on `main`. Carry its two record commits to a branch of their own. Once that lands, the daily branch sweep deletes the sent-back branch and its item returns to `bin/docket next` (`PL-W5JR`).
  - (902–905) Options. `--item <id>` runs one named item. `--per-run-usd` caps the cost of one run (default $15). `--no-push --model claude-sonnet-5-5` is the form used for `PL-6FX6`'s trial; with it the clone cannot push and the work stays on your machine.
  - (905–907) Reported cost. Each run's reported cost is Claude Code's own estimate and can differ from the bill, so read the Console's figure again at each launch rather than carrying forward the runner's last figure.
  - (908–910) Old ledger. Runners before `PL-NQ0M` kept a ledger at `~/.local/state/open-anesthesia-sim/api-credit-ledger.jsonl`. Nothing reads it now, so you can delete it.
