## Two constraints recorded beside the request

`open-anesthesia-sim` is a repository name; whether it is also the product name
is open, and icon, wordmark, window title and bundle identifier all derive from
that answer.

**A splash screen, if there is one, is a safety surface.** It would be the last
screen before any modelled number, which makes it the least skippable place to
carry the educational-simulation-not-for-clinical-use statement — and at the
same time the place where polish does most to make a simulator read as a
shipped clinical product, which `CLAUDE.md`'s clinical-output standard already
governs. So scoping this decides what a splash screen *says*, not only what it
looks like.
