The project owner decided to adopt. `venous_pool_volume_l` is **1.222 L**, from Davis and Mapleson's combined venous pool for inhaled-anaesthetic models, and the key is renamed in the same edit because a rename and a revalue on one key — touching a protected path, the loader, the balance, the provenance table and the fixtures — is one review rather than two.

This is the first value in `reference_adult.json` to carry a source other than the Gas Man Workbook.

## What tipped the decision

The case for keeping 1.0 L rested on preserving Gas Man comparability. `PL-3YZW` (merged in #418) established that 1.0 L was never in the Gas Man set: it entered at v0.1.0 under a Workbook citation belonging to its neighbours, and all four sources ever cited for it have now been read without finding it. Keeping it preserved nothing, so the choice was between a value with tier-2 published provenance and a value with none.

## Measured before the change, not asserted after it

| Wash-in `F_A/F_I` at 30 min, four cohorts | +0.15, +0.31, +0.79, +0.38 SD | +0.16, +0.31, +0.79, +0.38 SD |
| Elimination `F_A/F_A0` at 5 min | +3.67, +4.02, +1.02 SD | +3.79, +4.15, +1.13 SD |

The wash-in comparison **cannot discriminate between the two values** — the pool is long equilibrated by 30 minutes — so it is no evidence either way, which is worth knowing about that gate as much as about the parameter.

The elimination comparison moves **0.11 to 0.13 SD further from** its cohort means, because a larger pool returns more agent to the lungs. That is the same direction `test_published_wash_in.py` already attributes to this model's rebreathing circuit rather than to tissue return, and it is a tenth of a gap that is already 1 to 5 SD wide for apparatus reasons. Recorded in `docs/MODEL.md`, in the module's two measured tables and in the item rather than left to be discovered.

## The rename

`venous_pool_volume_l` is the name `docs/MODEL.md`'s provenance table was already using, which `PL-BD94` recorded as evidence the ambiguity had been felt before. `mixed_venous_mixing_volume_l` was the alternative and was not taken: more explicit, less readable, and not what a reader of the specification has already met.

`ROADMAP.md`'s v0.4.6 baseline still names the old key and is deliberately untouched — it records what that release established, and editing it would falsify the release history rather than fix a stale statement. The old name also survives correctly in one historical sentence in the Meybohm `sources` note, which is why the `verify:` command checks the stored key and value directly rather than grepping prose.
