## The tool

`tools/core_vocabulary_check.py` — standard library only, wired into `make check` and `.github/workflows/quality.yml`. Three rules, all decidable:

1. **Every Code cell in § "Symbols" resolves.** The table is parsed, `core/` is parsed with `ast`, and each `ClassName.accessor` must name a real field, property, method or `self.` attribute on a class defined exactly once. An em-dash cell is accepted only where it says what the code reads instead, and the substitute it names is resolved too. 24 cells today.
2. **The retired accessor names never come back.** `RETIRED_NAMES` transcribes `PL-9SH6`'s own table. Nothing is inferred from the tree — a name that has been removed leaves nothing behind to read.
3. **A partition-coefficient identifier names both phases, in order.**

## Two decisions the brief left open

**A new script rather than rules inside `tools/doc_check.py`.** The brief said to decide by whether the AST parse of `core/` fits there, and it does not. `doc_check.py` is invoked by a bare `python3` in `make check` and again in the CI floor section — the section that *proves* the standard-library-only promise by running these tools at the 3.11 floor. `core/` targets the version `.python-version` pins, and `ast.parse`'s `feature_version` only ever narrows the syntax accepted, so it cannot teach an older parser a newer language. This therefore joins `contrast_check.py`, `agent_identity_check.py`, `import_boundary_check.py` and `workflow_paths_check.py` under `uv run python`, and is deliberately absent from the floor section for the same reason they are.

**Rule 3 is decided by a declared phase ordering, not a closed list of permitted pairs.** `PHASES` is `("gas", "blood", "tissue")`, read outward from the gas phase, and an identifier must name the outer phase first — the order the symbol writes, so `tissue_blood_partition_coefficient` is the tissue:blood coefficient and cannot be read as its own reciprocal. An ordering admits a legitimately new pair with no edit while still refusing every reciprocal, which is the failure the literature invites: Baker and Farmery 2011 call one quantity the tissue-gas, the tissue-blood *and* the blood tissue partition coefficient in a single chapter. A qualifier before the phases (`fat_tissue_gas_partition_coefficient`) is unconstrained — it says which instance, not which phases. A new phase is one entry.

**Matching is on the whole identifier.** `require_concentration_fraction` and `BreathingCircuit.circuit_volume_l` each contain a retired accessor's text and neither is one — the first is `PL-6KNM`'s open question (whether the validator and `concentration.py` follow the rename), the second `PL-KZS3`'s. A substring rule would have failed the tree on the day it landed, over two names nobody has agreed to change, which is the shape of a check that gets suppressed rather than obeyed.

**What is deliberately not scripted** is whether a name is the one a reader who knows the domain would guess. That is the judgment the whole convention is about, and a tool guessing at it would be worse than no tool because its output would look authoritative.
