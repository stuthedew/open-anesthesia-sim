The project owner asks for **MAC-awake and 1 MAC drawn together and visually distinct**. This records that scope change in `PL-F52R`, which previously specified a single band. Documentation only — no code, no data-file change.

## Why the change is right

Chortkoff 1995 states that *"along with pharmacokinetics, the ratio of the awakening concentration to the anesthetizing concentration (MAC-awake/MAC) determines time to awakening."* Drawing both makes that ratio the **visible gap between them**, so the chart shows the decrement required for arousal rather than only the endpoint. That is the context-sensitive emergence lesson stated geometrically.

## Let the mark type carry the distinction, not the colour

| | Mark | Why |
| --- | --- | --- |
| MAC-awake | a **band** | A measured population value with real spread — Katoh ± 0.05 MAC, Chortkoff ± 0.46 % |
| 1 MAC | a **line** | A definitional anchor, not a distribution of the same kind |

Band-versus-line reads correctly in greyscale and under any colour-vision deficiency, so it satisfies `.claude/rules/ui-color.md`'s "colour is never the only channel" without a second cue bolted on. New colours still owe an entry in `tools/contrast_check.py`'s `REQUIREMENTS`, naming the background each is actually drawn on.

## The hazard the second reference introduces

MAC is by name and determination an **alveolar** quantity — Rampil 1991 determined desflurane's MAC as an end-tidal percentage. The MAC-awake figure this item draws is Katoh's slow-washout value, which the **Required property** section already places against the **vessel-rich** trace, and which Katoh attributes to end-tidal-to-arterial and arterial-to-cerebral gradients.

Two horizontal lines across one chart invite reading both against whichever trace the eye reaches first — the hazard that section already names, now with two chances instead of one.

**The asymmetry is the design answer.** After a long case the traces have converged, so the 1 MAC anchor is robust to which one it is read against; at MAC-awake they differ by 2.2× (3.01 min vs 6.72 min, measured in the item). So the labelling budget belongs on the *lower* reference, and the 1 MAC line should not acquire equal visual weight merely because it is easier to draw.

One consequence to expect rather than treat as a bug: on a short case the vessel-rich trace never reaches the 1 MAC line, because it never equilibrated. That is true and worth teaching.

## One decision taken rather than handed on

The line is the **nominal** 1 MAC from `mac_percent`, not the dialled setpoint — a fixed reference keeps the twenty-minute and three-hour cases comparable side by side, whereas a line tracking the dialled concentration would only restate where the trace already starts. Labelled "1 MAC (reference adult)", since `mac_percent` is a flat adult value while Katoh expressed MAC-awake against *age-adjusted* MAC.
