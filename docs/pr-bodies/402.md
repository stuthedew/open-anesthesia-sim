## What was wrong

`docket concurrent` reported three different relations under one heading, "Cannot run alongside":

- a `blocked-by` edge — the work genuinely cannot be done yet;
- two items naming the same file — ordinary, and the practice this project documents is to land the smaller change first;
- an overlap that exists only because one item declared a *directory* covering the other's file — weaker still, since it never claimed that file.

Only the first is a refusal.

## What it cost

27 of Gate 1's 112 open entries declare `docs/MODEL.md`, so the gate's science half — its most expensive work, the items wanting the strongest model — excluded itself from every batch. 38 of the store's 202 declaring items name a directory, which produced the same refusal in the same words.

Asked for three gate items that could run concurrently, the session that found this read the refusal literally and withheld `PL-4GN8` (P1, science-classed, the strongest item in the gate) because a running session on `PL-6Q8N` also declares `docs/MODEL.md`. They edit different sections.

## What changed

- `Conflict` gains a `strength`; `conflicts_for` tiers into `ordering` / `same file` / `same area`, and `refusals()` is the subset that forbids concurrent work.
- `parallel_batch` fills in two passes: the independent set first, then — only when `--limit` asks for a batch of a given size — items whose sole contention is a declared path. Unlimited, the batch is exactly what it was.
- Filled entries are annotated in the output with what they share and with which item, so the batch never claims "no declared overlap" over work that has some.
- `sequenceable()` names what a shared file alone kept out of the batch.
- The rule change is documented in `subprojects/docket/README.md` and in the `docket` skill's concurrency section.

The alternative route the item recorded — a sub-file unit for `touches`, so two items in different sections of one file never register — is declined rather than deferred: it changes the item format, every declaration wanting the precision, and the parser, for a payoff bounded by how long `docs/MODEL.md` stays this contended.
