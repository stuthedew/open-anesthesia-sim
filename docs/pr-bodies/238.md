## `PL-QSWS` — the gap the longer horizon exposes

Nothing in `docs/items/` or `ROADMAP.md` covers dependency and toolchain drift.
Searched 2026-09-02: no open item mentions an upgrade, a deprecation or an
end-of-life, and `ROADMAP.md` has no horizon language at all. Meanwhile every
constraint in `pyproject.toml` was written for what was current:

- `requires-python = ">=3.14,<3.15"` — one CPython minor, repeated in three
  more places (`target-version`, `python_version`, `.python-version`). Wrong
  within twelve months, and three to five times over this horizon.
- `flet[all]>=0.86,<1.0` — Flet is **pre-1.0**, so the upper bound excludes the
  release most likely to break the whole presentation layer and says nothing
  about what to do when it lands.
- `mypy`, `pytest` and `ruff` are unbounded floors, so the quality gate's
  behaviour changes under the project without notice.

The instance is already in the repository. `pyproject.toml` carries a comment
recording that pydantic 2.12.4 began passing `prefer_fwd_module=` to
`typing._eval_type`, a keyword CPython added between 3.14.0rc2 and 3.14.0
final — breaking deferred-annotation evaluation in `core/parameters.py`, the
validated-parameter boundary, and closed upstream as "not planned". One
dependency moving one patch version against one interpreter build broke the
scientific core's parameter loading, inside a single release.

**The brief recommends a policy decision before any mechanism**, and names
three candidates with a recommendation (a periodic scheduled run against the
latest interpreter and unpinned dependencies, reporting rather than gating). It
explicitly declines to build anything first: a scheduled job with no agreed
response to a red result is the advisory nobody acts on that `PL-ZBJ0`'s
retirement test now forbids adding.

This also qualifies the audit that preceded it. That audit judged the codebase
structurally healthy on current-state measurements — no import cycles, median
function length 13 lines in `docket` and 7 in `src/`. Those say nothing about
drift, which is exactly the failure mode a longer horizon adds.
