## `PL-C1KK` — and the answer is to name no baseline at all

Two lines called v0.2.3 the current released baseline. By the time this was

The item's open question — whether these lines should name a version at all — is
answered in the direction it proposed. Both were second copies of facts the file
already carried in a form that cannot go stale, which is why nothing ever read
wrong:

- § "Status" said the model was "implemented starting in v0.1.0 and still in
  force in v0.2.3, the current released baseline" — while the **very next
  sentence** already said the equations and compartment structure have not
  changed since v0.1.0. The version-proof sentence stays; the other is replaced

  version should say what has been true *since* one. That last part is what

- § "Known limitations" opened "As of v0.2.3, this model does not model:". The
  stamp did no work the list did not do better — entries that changed already

so this closed a stale citation rather than a wrong claim — its cost was
