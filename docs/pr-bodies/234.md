## Two independent sources agree at 0.36 MAC

| Source | Population | MAC-awake | As a fraction |
| --- | --- | --- | --- |
| Chortkoff 1995 | 22 male volunteers | 2.60 ± 0.46 % | **0.36 MAC**, stated in the paper |
| Song 2005 (control arm) | non-jaundiced surgical patients | 2.17 ± 0.25 % | 0.36 MAC against Rampil's 31–65 yr MAC |

Different populations, different countries, twelve years apart, neither derived from the other. In order beside Katoh: isoflurane 0.31, sevoflurane 0.34, desflurane 0.36 — so the **First step.**'s question is answered. One fraction does *not* cover all three, but the spread is narrow and each agent should carry its own value.

## The trap this records

Chortkoff's 0.36 is anchored to a MAC of **7.22 %** (2.60/0.36), which is Rampil 1991's **18–30 yr** figure of 7.25 %. This repository records `mac_percent: 6.0`, Rampil's **31–65 yr** figure.

Taking Chortkoff's *absolute* 2.60 % and dividing by the 6.0 % in the data file gives **0.433 MAC — 20 % above the published 0.36**, drawing the band too high and teaching a later wake-up than the literature supports. Song's 2.17 % escapes this only because its population happens to match the denominator.

Two consequences recorded in the item:

- **Store the fraction, never the absolute percent.** Katoh already expressed MAC-awake as a ratio to age-adjusted MAC, so the fraction is what all three sources share, and it is the only form that survives `mac_percent` changing or becoming age-aware.
- **Record which MAC each fraction was derived against.** A fraction with no stated denominator is the wrong-context failure the clinical-output standard names.

## A limitation recorded with the value

Katoh's slow-washout arm is *descending*; Chortkoff and Song both used *ascending* stepwise equilibration. All three are equilibrated rather than fast-washout determinations, which is why 0.36 belongs against the vessel-rich trace alongside Katoh's 0.34/0.31. But ascending and descending determinations are not interchangeable, and no descending-washout desflurane MAC-awake was found on PubMed — so `docs/MODEL.md` should say this rather than presenting the three fractions as if measured identically.
