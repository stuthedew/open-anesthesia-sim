`doc_check` read neither of the two places this project actually writes citations from: the queue, which is most of its prose, and source docstrings, which are where a contributor reading the code is sent somewhere else.

## Why not the widening the item described

`PL-X2XX`'s brief prescribed widening `DOC_GLOBS` to `docs/items/*.md` and `.py`. That was measured against the tree before anything was built, and rejected:

- It catches **neither** instance `PL-8B1K` was filed for. One no longer exists (`PL-006` rewrote that docstring); the other is missed by `CITATION_RE`, not by `DOC_GLOBS`.
- It adds **16 section-citation errors and 143 unresolved path citations**, of which about five are real. Item briefs quote program output, GitHub settings labels and other documents' headings; 111 of the path citations are in closed records that are correct as history.
- It would hand 687 item files to `check_make_targets` and to `candidates`, neither of which wants them.

The measurement is recorded in the item, so the reasoning outlives the branch.

## What this does instead

**`CITATION_RE`'s quoted title may span a source line** (`PL-X94L`). Prose here hard-wraps at about 78 characters, so a section title long enough to wrap could not match — and unmatchable meant *unexamined*, not reported. 18 citations in the documents `doc_check` already reads had never been looked at.

**`_headings` returns `**Bold.**` markers as well as `#` headings.** This project subdivides long documents with them and cites them by name — `docs/MODEL.md` carries 513 against 269 headings, and cites its own. Reading only `#` lines made a *correct* citation look stale, which is the worse direction to be wrong in: a reader sent to repair prose that was right.

**`check_quoted_sources`** holds a citation that names a document and then quotes it — the form `PL-042` writes, which no existing branch matched — to that document, over `DOC_GLOBS` + `docs/items/*.md` + every module, class and function docstring.

The test is **containment, not headings**, and that is what makes it exact. Whether a quotation is a section title or a sentence is a distinction the tool would have to guess at, and guessing produced six false errors against prose quoted correctly. Whether the named document contains the words is decidable, it is the same question either way, and a quotation that has drifted is as stale as a title that has. Case, dash style and quote style are folded, because a passage copied by hand settles on one of the forms this project writes. Elided quotations and fenced blocks are skipped, so an item can show the broken citation it is reporting.

`DOC_GLOBS` itself is untouched, so `check_make_targets` and `candidates` are unaffected.
