Captures the goal of holding UI color and interface design to WCAG, then lands the three parts of it that are actionable now. Five items were captured; three are closed here and two stay open.

## The gap this closes

The project applied WCAG in three places and stated a target in none. `app/theme.py` cited SC 1.4.3's 4.5:1 for the agent fill/foreground pairs — as a comment, with nothing computing it. `PL-GVXP` (separate the six chart traces by more than colour) held the traces to SC 1.4.11's 3:1, measured by hand. `ROADMAP.md` item 20 parked accessibility generally.

The tell is in the tree: the three ISO 5360 agent colors got full provenance plus simulated dichromacy analysis in `docs/MODEL.md`; the six trace colors immediately beside them got none. Same files, same sessions, no rule in between — and `.claude/rules/expert-review.md` already listed color and contrast as review domains, so naming the domain was demonstrably not enough.

## What landed

**`PL-MMYM` — the target, recorded in `docs/MODEL.md`.** WCAG 2.2 Level AA. WCAG 2.2 is the current W3C Recommendation; WCAG 3.0 is a Working Draft whose scoring model replaces pass/fail entirely, so it is not designed against here. Two places the project holds itself *higher* — color is never the sole channel (the ISO 5360 reasoning is stronger than SC 1.4.1's floor), and chart traces are held to pairwise separation, which WCAG does not cover at all. Four criteria deferred by name (2.4.11, 2.5.8, 1.4.10, 1.4.12) so the deferral is visible rather than silently unlisted.

**`PL-1MK1` — `tools/contrast_check.py`, in `make check` and both CI jobs.** Standard library only; reads the color constants out of `app/` with `ast` rather than importing them, because `app/simulation_view.py` imports Flet and these tools run under a bare `python3`. The `REQUIREMENTS` table is the specification — each entry names a pair that appears on screen together, the criterion, the minimum, and the reason — and a person writes it. The tool evaluates it and decides nothing else.

**`PL-HC9P` — `.claude/rules/ui-color.md`, scoped to `src/anesthesia_sim/app/**`.** Carries only the judgment half the checker cannot decide. The resident instruction count is unchanged at 505 lines, which is the routing working as intended: this loads when a session reads the interface, and costs nothing when it does not.

## One result worth recording

Contrast composes along a bounded axis, so no arrangement of six traces gives every pair more than 21^(1/5) ≈ **1.84** — below SC 1.4.11's 3:1. A redundant non-color channel is therefore a *requirement* for the chart rather than an embellishment, and no palette choice can remove it. That bounds `PL-GVXP` (separate the six chart traces by more than colour) rather than replacing it, and the tool prints the ceiling beside the pairwise matrix under `--matrix`.
