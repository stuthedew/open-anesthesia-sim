## What it does

Three module-private helpers replace the comprehension, because one comprehension over three node types could not carry the reason each form contributes what it does:

- `_package_imports` reads the source text and reports one name per import site.
- `_reached_by_importing_module` decides a plain `import`. `import anesthesia_sim.core.x` binds `anesthesia_sim`, not `x`, so the dotted tail is not what the importer got hold of; the subpackage is the coarsest true description, and no subpackage is on `ALLOWED_PACKAGE_IMPORTS`, which lists names taken *from* a module. A bare `import anesthesia_sim` reaches all of it and is reported under its own name.
- `_dynamic_import_target` decides `import_module` and `__import__` where the source states the module literally, and declines what reading the source cannot settle — a computed name, or a relative one, which cannot reach out of the importing tree.

`_DYNAMIC_IMPORTERS` matches `tools/import_boundary_check.py`, which had already settled the dynamic-import shape; `_dynamic_import_target` follows its `_dynamic_root` closely, including declining a relative literal.
