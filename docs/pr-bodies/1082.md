Before: `gate-status-guard.sh` refused `{ set -o pipefail; uv run pytest -q t.py 2>&1 | tail -12; }` and the same inside `( ... )`, though both keep the gate's status, and told the session to add the `set -o pipefail` the command already carried. Two causes, not the one the brief named: `sets_pipefail` read a segment's first word without stripping the `{` or `(` that `gate` strips, so a `set` opening a group never counted; and the `;` a brace group needs before its `}` read as handing the status on, so even `{ make check; }` and `( make check; )` were refused.

After: a group is read the way bash runs it. A `set` lasts as long as the shell it runs in, so a `set -o pipefail` opening a group covers the pipes after it: to the group's end where the group is a subshell (`( ... )`, a substitution, or a `{ ...; }` group that is piped or backgrounded), and past the `}` where a brace group runs on its own. A `;` before the `}` or `)` that ends a group hands the status to nothing; the separator after the group decides the rest.

The scoping is bash's rather than a looser one on purpose. Crediting a `set` to everything after it was the shorter fix, and it would have passed `(set -o pipefail; make check) | tail` and `{ set -o pipefail; make check; } | tail`, which lose the status in bash exactly as PL-2JRC's command did. Those are still refused, and the refusal now says why: a command that visibly sets `pipefail` and is refused anyway reads as the guard being wrong, which is the lesson this item was filed against.

How: `command_words` is the one reader of a segment's head, used by both `gate` (through `strip_prefixes`) and `sets_pipefail`. `pipefail_by_separator` walks the segments once, pushing a frame at each group opener and restoring the state at each close where the group was a subshell, and the separator walk reads the state at each `|` rather than one value per gate. A `)` is counted by character, because the lexer glues a run of punctuation into one token (`;)`).

Tests: `test_pipefail_set_inside_a_group_keeps_the_status` replays both group spellings and the item's command verbatim; `test_pipefail_set_in_a_subshell_ends_with_it` holds seven shapes that still lose the status, each of which a naive-scoping mutant of the hook lets through; `test_the_semicolon_that_ends_a_group_hands_the_status_to_nothing` covers the second cause.
