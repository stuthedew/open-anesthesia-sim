## Decided, and recorded as a decision

**MAC basis (project owner, 2026-09-02).** `mac_percent` moves from the flat Gas Man values the agent files carry (sevoflurane 2.0, isoflurane 1.2, desflurane 6.0) to the Mapleson MAC40 basis, in the release that adds age.

Nickalls and Mapleson (Br J Anaesth 2003;91(2):170-4) is already cited in all three of `data/agents/*.json` with a note recording that it is *not* used because the model has no age parameter — this is that note becoming live. The consequence worth naming: the reported MAC40 figures are not the values the files carry, so the displayed MAC changes at every age **including 40**. It is a parameter-set change needing a provenance row and a release note, not a new input field, and it lands after `PL-DHV7` (MAC multiples as a display unit) since an age-adjusted MAC with no MAC unit to show it in changes nothing a learner sees.

The MAC40 figures are written down to be confirmed against the primary paper when the milestone is scoped, not copied from the roadmap — the same provenance standard every other value in `data/` is held to.
