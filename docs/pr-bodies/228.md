Closes `PL-P0QT` (a merge resolution can delete a captured item with nothing recording that it did), and carries three captures filed earlier on this branch.

## The problem

A conflict resolution removes an item file in the **merge's own tree**. A merge is not diffed against either parent, so `git log --diff-filter=D -- docs/items/` returns nothing and the loss leaves no trace a reviewer would find. `PL-Q8QX` went that way on the v0.3.0 release branch and survived only because one container still held a stale `origin/` ref.

## What this adds

`vcs.lost` walks the objects instead of the diffs: every blob path reachable from a ref, compared against the ids its tree currently holds. Anything the history held and the tree does not becomes an **error** in `docket check`, carrying the `git cat-file -p BLOBSHA` line that recovers the file as it last stood.

- Comparison is by **id, not path**, so a renamed item file is not a loss.
- An error rather than an advisory: this is the capture rule itself failing.
- A clean answer from a truncated clone says so rather than claiming history it could not read.

## Where the design departs from the item

The item asked for a check run on `main`, comparing it against merged branch tips. **Measuring it changed the design.** After a squash merge the branch's commits are ancestors of nothing, so its objects stop being reachable — `PL-Q8QX`'s blob is reachable from no commit `main` holds. A check run there reports the store clean and is wrong to, and a false clean bill of health on the capture rule is worse than no check at all.

So the walk asks the **branch**, in CI, on the pull request, before the squash collapses the history. It still catches an ordinary merge on `main`; nothing run there can catch a squashed one. That limitation is documented rather than hidden.

## Verification

- `--diff-filter=D` really does miss the deletion (if this ever starts failing, the cheaper read would do).
- `rev-list --objects` really does list newest-blob-first, which is what lets the report hand back the item as it last stood rather than as it was captured.
