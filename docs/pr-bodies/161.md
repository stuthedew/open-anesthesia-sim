## Why a disclosure clause and not an ordering one

Rule 14's ordering clause is already correct — "one has to land before the next makes sense" covers this case exactly, and it explicitly warns that "a numbered list states an order whether or not one was meant." It was misapplied, not deficient. What the rule did **not** require is that a line disclose its own output, and a line that reads as a question is precisely the one that gets sorted as one.

So this adds a disclosure requirement rather than a second ordering rule. A second ordering rule competing with the first is how this file would start contradicting itself.

```
- A line whose answer will produce a commit says so, and sorts as work
  rather than as a question. Where that commit belongs in a branch another
  line would merge or close, the decision line comes first — otherwise it
  is answered alongside the merge and its answer is orphaned.
```
