## What changed, and how

The chart's hover used to take, for each trace separately, the drawn point nearest the pointer measured in two dimensions (time and percent, in pixels). On a sloped trace that let the pointer's **height** choose which grid column answered, so two compartments of one run could be labelled with two different instants inside one box, and a purely vertical hand movement could change the instant, and the printed value with it, while nothing else in the box moved.

Now the pointer's position along the time axis names the instant. Each run finds its drawn column nearest the pointer in time once (`_nearest_column`: one bisection, a tie going to the earlier column), and each visible compartment answers there only if that point is inside the 12 px radius. The wash-in plot's hover uses the same rule across a run's stretches (`_nearest_wash_in_point`). The readout's text forms are unchanged: every line still states its instant, because two runs can still differ (each draws its own control-event columns, and a branch draws nothing before its fork). Within one run the lines now always agree.

## The trade-off, and the alternative refused

The radius is measured to the point **at the named instant**, not to the nearest of the trace's points. So every value the box reports is at the instant the pointer names and within reach of it. The cost is aim beside a steep segment: of the area each trace used to answer over, 84-100% is kept on the 60-minute and 2-hour axes, and 45-54% for the four fast compartments on the 12-hour axis, where dial changes are near-vertical steps. Nothing is answered that was not answered before, and no drawn instant becomes unreachable (one off-grid control-event column on the 12-hour axis, 1 of 151, is reachable only from half-pixel positions).

The alternative that keeps the old answering area (old reach, value reported at the named instant) was measured and refused: where this rule declines, it would report a point a median 13.5 px and up to 42.5 px from the pointer on the 60-minute axis, and up to 146 px on the 12-hour one, with the dot and the box hung on a value the reader is nowhere near.
