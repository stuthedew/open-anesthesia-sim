## What changed

Three paragraphs replace the stale one, and one clause upstream of them:

**The port is done, so this is unblocked.** `PL-QXSB`'s decision to leave Flet
has been carried out and `tools/import_boundary_check.py` refuses `flet` and
`flet_charts` in every module under `src/`. Nothing is waiting on anything —
`PL-ZG5J`'s own open decision is the only thing between it and a harness.

**The method survives; its third stage now measures the paint.** Under Flet
the stages were `controller.advance`, `_refresh_view` and `page.update()`, and
the serializing connection was the subtle part. Qt serializes nothing, and
what sits in that position is the paint: `ChartPlot.draw` is `setData`,
`setPos` and `setTicks` throughout, so `_refresh_view` returns before the
frame has been drawn. Measured in this container over 20 frames, one run
warmed to an hour of simulated time, 600 steps per frame at 300x against the
200 ms `RENDER_INTERVAL_S` budget:

| stage | median |
| --- | --- |
| `controller.advance` | 14.9 ms |
| `SimulationView.present(False)` | 18.8 ms |
| `QApplication.processEvents()` | 15.5 ms |

So the interface costs 34.3 ms and a two-stage reading of it is 18.8 ms — 45%
low, in the flattering direction. A second `processEvents` immediately after
the first costs 0.10 ms, which is the control: the 15.5 ms is the paint that
first call dispatched, not fixed event-loop overhead.

**What it costs to build now: 42 lines, no new dependency, ~3 s to run.**
`tests/integration/test_qt_rendering.py`'s `dashboard` fixture is already
every line the harness needs before its first `perf_counter`. One environment
fact went in beside the decision: `tests/conftest.py` sets `QT_QPA_PLATFORM`
for the test tree only, so a script run outside pytest must set it itself —
an argument for the test tree over a `bench/` one rather than a decision.

**The dependency clause** in "What is unresolved is where it goes" now names
`PySide6` and `pyqtgraph` rather than `flet`, `flet_charts` and `msgpack`. The
stdlib-only objection survives the substitution, so the decision is unchanged
in shape and narrower in substance.
