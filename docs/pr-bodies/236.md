## The bar that selected them

The audit found that the queue's own machinery had several guards failing
*open* — `bin/docket check` reporting clean while the guarantee it stands for
was void. `CLAUDE.md`'s friction-that-compounds rule previously used an
arithmetic test (per-item saving times items remaining). It now names three
properties instead, any one of which earns an interruption of feature work:

- it **gives a wrong answer silently**, so a check passes while its guarantee
  is void;
- it **is being routed around**, a warning firing so routinely nobody reads it;
- it **sits upstream of everything**, in the store or gate every command reads.

Paired with a retirement test beside the existing build gate: a check that
fires every run without changing a decision is a defect in the check, and
removing one is a legitimate outcome of a workflow pass rather than a loss of
coverage. Resident context grows 10 lines; `doc_check.py` reports it.
