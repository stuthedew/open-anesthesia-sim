The hover opened `Modelled sevoflurane · 20m8s` and named everything about the point except the one thing that distinguishes it in compare mode. It now reads `Modelled sevoflurane · Run 2 · 20m8s` while more than one run is drawn, and is unchanged while one is.

Decided by the project owner on a session's recommendation (ratified), over giving the run a fourth line of its own and over holding the curve's line width and the legend to be sufficient.

## Why line 1, and why conditional

Line 1 is the line `docs/MODEL.md` already calls *run context*, so naming the run completes it rather than changing the three-line form the rest of that section derives. In compare mode it is also the only token on that line that tells the runs apart: `assemble_chart_frame` refuses a frame whose runs differ on agent, so the agent is constant across the runs being compared.

It is conditional for the reason `run_trace_style`'s width channel is — a single run has nothing to be told apart from — and that is not a hidden mode: a second run brings a second legend entry and a second readout panel with it.

## The counter-argument was measured, and is false

The item argued against itself: the pointer is over one curve, and the curve's width says which run. `nearest_trace_point` keeps the single globally nearest drawn point across *every* run on the frame, so the pointer is within reach of both wherever their curves for one compartment run close together.

Measured on a branched sevoflurane case — reference adult, trunk held at 1 MAC, branch forked at 10 min, 60-minute axis at 900x360 px, so 4.00 s/px and 0.0167 %/px. Share of the shared axis on which both runs' points for one compartment sit inside the 12 px hover radius:

| Branch's management at the fork | Alveolar | Fat |
| --- | ---: | ---: |
| doubled to 2 MAC | 1.6% | 100% |
| raised to 1.25 MAC | 8.5% | 100% |
| vaporizer turned off | 1.6% | 100% |

The count that would have killed the case — whether both runs print the same text there — came back the other way: 83.3–95.3% (alveolar) and 43.8–81.4% (fat) of those hovers print *different* values. On the emergence case the fat hover at 3492 s reads either `0.03%   0.02 ×MAC` or `0.01%   <0.01 ×MAC`.
