Before: `.claude/hooks/no-prune-guard.sh` had no shape for `git push`. `git push --mirror origin` and `git push --prune origin 'refs/heads/*:refs/heads/*'` ran unrefused, though each deletes every branch on the remote that the pushing clone does not hold, other sessions' unmerged branches among them, while `git fetch --prune`, which deletes only this clone's copies, was refused.

After: a `git push` carrying `--mirror` or `--prune` is refused wherever the flag stands among its words, and so is a mirror push made through the `remote.origin.mirror` setting, whether passed with `-c` or `--config-env` ahead of the command name or written with `git config`. The refusal carries its own recipe: push the branch by name, and leave deleting branches on the remote to the owner. The fetch recipe it would otherwise print is not true of a push.

git reads that setting as the flag itself: its push documentation at v2.43.0 makes `--mirror` the default for any remote whose mirror setting is on, and `git -c remote.origin.mirror=true push origin` deleted the branch on a scratch remote.

How: `PUSH_SHAPES` holds a `push` shape and a second `config` shape beside the fetch-side `SHAPES`; `sets_pruning` became `sets(pattern, words)`, so one reading of the settings ahead of the command name serves both; `runs()` asks each family, and the hook joins the reasons that apply. Two refusals are deliberate and pinned: `--prune` is refused with any refspec, because a push naming none takes its refspec from a config file the hook never reads, and a `--dry-run` beside either flag is not read. Out of reach, recorded in the hook header beside its other limits: an abbreviated `git push --mir`, and the mirror setting that `git remote add --mirror` and `git clone --mirror` write. Whether GitHub branch protection or the harness push proxy would stop such a push was not checked; the guard does not rely on either, and the check would be the push itself.

`PL-YFT4`'s brief gains one paragraph: the new `config` shape refuses `git config --get remote.origin.mirror`, a read, for the cause `PL-YFT4` fixes on the prune setting, so its fix is owed on both.
