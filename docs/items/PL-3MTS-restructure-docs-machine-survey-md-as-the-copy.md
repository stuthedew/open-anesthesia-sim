**Problem.** Restructure docs/machine-survey.md as the copy editor's structure read proposes

**Where this comes from.** The copy editor's structure read of the document, run on 2026-11-05 under the owner's request of that day to copy edit every human-facing document. The owner chose to line edit each document first and restructure it later, so this item holds the read's outline findings, verbatim, for that later pass. The read's per-chapter findings are in the project's shared files under `v0.7.0/repo-copy-edit/runs/docs-machine-survey-md/structure/`, and the pass should read them too. Each "Query" below is a question the document could not answer for itself; answer it from the sources it names, or file it as its own item.

**The outline read, verbatim.**

- **Query, rows 132-548:** § "The variables" is the longest chapter, but it has no outline lines, so this read could not compare it with the other chapters. Several likely repeats therefore cannot be confirmed: Shin's volumes (rows 29-36, 109-112, 590, 715-721), the § "(a2)" judgments below, the Tec 6 desflurane maximum of 18% (row 594), and the labels (a1), (a2) and (b1)-(b11). § "Ruled out" and § "What `PL-FG9D` needs: data against behavior" use those labels without defining them. Rerun this chapter's read with its outline.
- **Same point in two places, rows 12-15 and 552-554:** "A specification with no path that somebody would otherwise raise again gets one line under § 'Ruled out'" and "written once for the whole survey rather than once per machine, one line each". The one-line rule belongs in rows 12-15. Rows 552-554 keep only that each line gives the condition that would bring the item back.
- **Wrong pointer, rows 17-20 against rows 581-635:** rows 17-20 say "The document's last section gives `PL-FG9D` what it needs: which variables are per-machine data and which are different behavior." That section is the seventh of nine. It also holds a third class, inlet position and layout, which it calls "neither data nor behavior" and "the finding to decide now" (rows 622-623). The chapter order itself works, because that section's table of unknowns leads into § "What is missing, and how the next session gets it".

- **Query, rows 29-36 against rows 109-112, 590 and 715-721:** the headline finding says Shin "computed each one's circuit volume" (Perseus A500 3.3 L, Zeus IE 3.2 L) and calls circuit volume "the model's only machine parameter". Are 3.3 L and 3.2 L the tier-2 apparatus volumes? Did Shin compute them or copy them? Does the model take the circuit volume or the apparatus volume?
