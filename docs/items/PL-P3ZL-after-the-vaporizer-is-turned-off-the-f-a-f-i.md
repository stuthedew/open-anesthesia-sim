**Problem.** The line above the F_A/F_I plot says "Not defined: no agent has reached the circuit yet." (`WASH_IN_NOT_DEFINED_TEXT` in `src/anesthesia_sim/app/dashboard_frame.py`) whenever the inspired fraction is below 0.01%, the floor `read_wash_in` in `src/anesthesia_sim/app/wash_in.py` divides by. `docs/INTERFACE.md` § "A point is drawn only inside two boundaries" names only the start of a run and a run whose vaporizer is never opened as the cases below that floor. A run can also reach it after agent was given: with the vaporizer turned off, the inspired fraction falls below 0.01% during washout. `tests/integration/controller/test_controller_preview_crossings.py` builds such a run (8% sevoflurane for 30 s, then apnoea at 0.5 L/min with the vaporizer off), and its inspired fraction falls below the floor in its second hour. The caption then tells a learner that no agent ever reached the circuit while the patient still holds agent, and while the plot may report earlier wash-in stretches in the same line ("(2 earlier stretch(es) not drawn)").

The blind review of `PL-00Y5` found it on 2026-11-23, in a new test that pinned that contradictory line. The test was changed to leave the no-agent state out, so nothing now pins the wording this item changes, except `test_the_wash_in_trace_draws_nothing_before_agent_reaches_the_circuit` in `tests/unit/test_dashboard_frame.py`, which checks the start of a run, where the sentence is true.

**What to do.** Make the line true in both cases. One way is a wording that does not claim a history, such as one that says the inspired concentration is below the 0.01% the ratio is divided by. Another is a separate state for a run that has had agent in its circuit, which needs a fact the single reading does not hold. Research how a monitor or a teaching display labels a ratio whose denominator is too small, record the sources here, and choose. Update `docs/INTERFACE.md` § "A point is drawn only inside two boundaries" and the approved interface strings with it. Add a test that reaches the washout case through a run, as `.claude/rules/test-oracles.md` rule 2 asks.


**Done when.** The caption above the F_A/F_I plot says, wherever the inspired concentration is below the 0.01% that the ratio is divided by, only that it is too low to divide by, and claims nothing about whether agent has reached the circuit. A unit test drives a real run through a washout to that state and checks the sentence against a literal. `docs/INTERFACE.md` § "A point is drawn only inside two boundaries", the `WashInDomain` docstring and the approved interface strings say the same.

**Generator check.** A one-off. The fact misread is when the inspired concentration can be below the limit: the sentence and the documents named only the start of a run and a run whose vaporizer is never opened. No head's `misread:` names what a caption may claim about how a state arose.

**Research, 2026-11-23.** Neusesser and Sunwall, "Error-Message Guidelines", Nielsen Norman Group, 14 May 2023 (https://www.nngroup.com/articles/error-message-guidelines/, full page read): "Concisely and precisely describe the issue." The Philips IntelliVue MP20/MP30 instructions for use, technical alarm table for cardiac output (https://office.manualsonline.com/manuals/mfg/philips/mp2030.html?p=82, one page read) replace a numeric that cannot be derived with "-?-" and state the condition that stopped it, such as "CCI numeric unavailable" where the body surface area is missing. Both state the condition that stops the value and no guess at its cause, so the caption now names the condition. A page of the Edan Elite V5 manual was also read and says nothing on the question.

**The other route, and why not.** The brief also offered a separate state for a run that has had agent in its circuit. The reading holds both fractions, so the caption could have called a washout whose alveolar fraction is above the limit elimination, which it is. But the plot leaves that column blank because the inspired concentration is below the limit, the first of its two boundaries, and `wash_in_state` says the caption and the plot apply the same two boundaries. A caption naming the second boundary would give a different reason from the plot's. The concentration chart already shows the washout itself, so the wording change was taken.

**Done 2026-11-23.** The caption is now "Not defined: the inspired concentration is too low to divide by." in `app/dashboard_frame.py`, and the approved interface strings carry it. `docs/INTERFACE.md` § "A point is drawn only inside two boundaries" now names a washout as a third case below the limit and says the caption names the condition and not a cause, and its caption paragraph no longer quotes the old sentence. `app/wash_in.py`'s module docstring and `WashInDomain` docstring say the same. `tests/unit/test_dashboard_frame.py::test_the_wash_in_caption_names_no_cause_once_a_washout_empties_the_circuit` runs 8% sevoflurane at 10 L/min for 30 s, then closes the vaporizer and stops ventilation, and at 300 s finds the inspired concentration below 0.01% and the alveolar above it. Against the code before the fix it fails with "At index 0 diff: 'Not defined: no agent has reached the circuit yet.' != 'Not defined: the inspired concentration is too low to divide by.'". The test of the count of undrawn stretches now checks the no-ratio state too, which the old sentence contradicted. Documents checked: `docs/INTERFACE.md` (§ "A point is drawn only inside two boundaries" and the caption paragraph; § "Displayed precision" on `0.00%` still holds), `docs/MODEL.md` (its `0.00%` sentence still holds), `docs/VERIFICATION.md` and `README.md` (neither quotes the caption).

**Blind review, 2026-11-23.** Two passes. Both found that `_extends_a_stretch` in `app/chart_frame.py` and the last paragraph of `app/wash_in.py`'s module docstring still gave the old cause for a column with no ratio, and both now name the condition. Pass 2 found that the other caption of the pair, `WASH_IN_ELIMINATION_TEXT`, claims that the patient is returning agent when ventilation is stopped and no agent moves between the lungs and the circuit. That fault is older than this change and is filed as `PL-7PBB`. This change's own comment above the captions and the `WashInDomain` docstring now describe that second boundary as a condition, an alveolar concentration above the inspired, so they no longer repeat the claim. Both passes found that the Circuit readout shows an inspired fraction from 5e-5 to 1e-4 as "0.01%", the value the limit is named by, beside the caption that says it is too low to divide by. That is also older than this change, and is filed as `PL-FSXD`.
