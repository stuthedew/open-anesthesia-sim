**Problem.** Draw grey-box layouts of the Default Workspace for each of the four learner tasks, with no colour or styling

**Where this comes from.** The third step of the order of work the owner
agreed on 2026-11-10 (`PL-HS9M`). It waits for the heuristic evaluation,
`PL-8Q1P`, whose findings say what each layout must fix.

**What to do.** For each of the four tasks in `PL-8Q1P`, arrange the Default
Workspace in grey boxes, with no colour or styling. Try each of the seven
patterns that `PL-HS9M` lists from Arneson et al. as a hypothesis. The
`window-is-the-frame` feature decides the frame the layouts start from. A
headline answer, such as the time to reach 1 MAC, is a new computed value
and needs the owner's approval as a feature before a layout relies on it.

**Why it matters.** The interface pass styles a layout only after the layout works for the learner's tasks. Drawing the layouts without colour keeps the two questions apart, so a finding about where a value sits is not mixed up with one about how it looks.

**Done when.** Each of the four tasks in `PL-8Q1P` has a grey-box layout of the Default Workspace, recorded in this item beside the heuristic-evaluation findings it answers.
